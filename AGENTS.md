# Project Rules (AGENTS.md)

- **Architecture**: Static website, no backend.
- **Technologies**: HTML5, CSS3, Vanilla JavaScript.
- **Deployment**: Optimized for Cloudflare Pages.
- **Directory Structure**: All deployable assets must be in the `public/` folder.
- **Privacy**: Process all data locally in the browser. Do not transmit user input to external servers.
- **Quality**: Responsive design, accessible forms, and valid SEO metadata.
- **Maintenance**: No external dependencies or paid APIs.
