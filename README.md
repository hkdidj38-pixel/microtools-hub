# MicroTools Hub

A collection of free, privacy-focused online tools for productivity.

## Tools Included
- **Word Counter**: Analyze text length and word count.
- **Text Case Converter**: Transform text between Uppercase, Lowercase, Title Case, etc.
- **JSON Formatter & Validator**: Pretty-print and validate JSON data.

## Deployment on Cloudflare Pages

1. Connect your GitHub repository to Cloudflare Pages.
2. Use the following build settings:
   - **Framework preset**: None
   - **Build command**: `exit 0`
   - **Build output directory**: `public`
   - **Root directory**: (Leave blank)
3. Deploy!

## Privacy
All processing happens locally in your browser. Your data never leaves your device.
